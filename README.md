# PixelPro Agency

Sitio web de PixelPro Agency: fotografía, diseño, publicidad y tecnología. Mérida, Venezuela.

Es una página única (`index.html`) con el CSS, el JavaScript, el logo y las fotos incluidos. No necesita instalación.

## Publicar en GitHub Pages

1. Sube estos archivos a un repositorio nuevo de GitHub.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`, y guarda.
4. En uno o dos minutos la web estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.
